# EcommerceCMS

> CMS modular para comercio electrónico desarrollado desde cero con PHP 8.2.

---

# Descripción

EcommerceCMS es un sistema diseñado para administrar cualquier tipo de negocio.

Ejemplos:

- Tiendas de ropa
- Ferreterías
- Farmacias
- Restaurantes
- Electrónica
- Librerías
- Cosméticos

El objetivo es crear un CMS moderno, escalable y fácil de mantener.

---
